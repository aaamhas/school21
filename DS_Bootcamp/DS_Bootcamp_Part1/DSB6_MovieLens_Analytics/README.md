# DSB6 · MovieLens Analytics

Групповой проект первой части DS Bootcamp Школы 21, команда **TL_karlondo**. Модуль на Python анализирует фильмы, оценки пользователей и теги MovieLens. Jupyter Notebook объединяет результаты в отчёт с измерениями времени выполнения.

## Модуль анализа

| Класс | Возможности |
| --- | --- |
| `Movies` | Распределения фильмов по годам и жанрам, фильмы с наибольшим числом жанров |
| `Ratings.Movies` | Распределения оценок, популярность фильмов, средние и медианные оценки, разброс оценок |
| `Ratings.Users` | Число оценок пользователей, средние и медианные оценки, пользователи с наибольшим разбросом оценок |
| `Tags` | Самые длинные, многословные и частые теги, поиск тегов по слову |
| `Links` | Режиссёры, бюджеты, выручка и длительность фильмов, рейтинги по стоимости минуты |

Реализация и 28 pytest-тестов находятся в [`src/movielens_analysis.py`](src/movielens_analysis.py). Исходные шаблоны классов сохранены в [`code-samples/`](code-samples/).

## Отчёт

[Открыть movielens_report.ipynb](src/movielens_report.ipynb)

Ноутбук содержит анализ фильмов, рейтингов, пользователей, тегов и дополнительных сведений о фильмах. Для измерения времени используются команды `%timeit`.

## Данные

В [`datasets/`](datasets/) находятся четыре исходных файла.

| Файл | Число записей |
| --- | --- |
| [`movies.csv`](datasets/movies.csv) | 9 742 |
| [`ratings.csv`](datasets/ratings.csv) | 100 836 |
| [`tags.csv`](datasets/tags.csv) | 3 683 |
| [`links.csv`](datasets/links.csv) | 9 742 |

Основные методы чтения используют первые 1000 корректных записей. Для сопоставления идентификаторов с названиями фильмов используется полный список фильмов.

Метод `Links.get_imdb` получает дополнительные сведения со страниц The Movie Database и сохраняет их в [`src/imdb_cache.json`](src/imdb_cache.json). В сохранённом кэше есть сведения о 998 фильмах из первой тысячи записей. У двух оставшихся фильмов отсутствует идентификатор TMDB, они попадают в `Links.skipped`.

## Запуск

Нужен Python 3. Проверено на Python 3.13.7.

```sh
python -m pip install requests beautifulsoup4 pytest jupyterlab
cd src
python -m pytest movielens_analysis.py -v
python -m jupyter lab movielens_report.ipynb
```

Рабочим каталогом должен быть `src`. Код использует пути `../datasets/...` и ищет `imdb_cache.json` в текущем каталоге.

Для работы с сохранённой выборкой достаточно файлов проекта и кэша. Для получения сведений о других фильмах потребуется доступ к TMDB.

## Структура

```text
DSB6_MovieLens_Analytics/
├── code-samples/              # исходные шаблоны классов
├── datasets/                  # четыре CSV-файла MovieLens
├── src/
│   ├── movielens_analysis.py  # модуль и pytest-тесты
│   ├── movielens_report.ipynb # аналитический отчёт
│   ├── imdb_cache.json        # сохранённые сведения о фильмах
│   └── test.py                # ручная проверка страницы TMDB
└── LICENSE                   # исходный файл лицензии Школы 21
```

`src/test.py` выполняет запрос к TMDB и сохраняет страницу в `debug.html`.

В исходном `movies.csv` заголовок содержит `movieId,title` при трёх полях в строках данных. Метод чтения обрабатывает такие строки по позиции и сохраняет сообщение об укороченном заголовке в `Movies.error`.
